1. Начало программы. 

2. Объявить константы: количество строк N = 4, количество столбцов M = 3. 

3. Объявить целочисленный массив A размером 4×3. 

4. Установить начальное значение произведения base = 1. 

5. Установить флаг teres = false (означает, что положительные элементы пока не найдены). 

6. В цикле по всем строкам (i от 0 до N-1) и внутри него по всем столбцам (j от 0 до M-1) запросить ввод пользователя и сохранить значение в A[i][j]. 

7. Вывести пустую строку для разделения вывода. 

8. В новом вложенном цикле перебрать все элементы матрицы: 

a. Если текущий элемент A[i][j] больше 0, то: 

i. Вывести этот элемент на экран через пробел. 

ii. Умножить его значение на переменную base. 

iii. Установить флаг teres = true. 

9. После завершения циклов проверить значение флага: 

a. Если teres == true, вывести значение произведения base на новой строке. 

b. Если teres == false, вывести сообщение «HeT nolowuTelHux» (нет положительных).
