1. Начало программы. 

2. Объявить целочисленную переменную i для счётчика. 

3. Объявить символьный массив text размером 1000 символов. 

4. Запросить у пользователя строку текста с помощью cin.getline() и сохранить её в массив text. 

5. Вычислить длину введённой строки с помощью strlen(text) и сохранить в переменную len. 

6. Установить флаг end = true (означает, что текущая позиция находится в начале предложения или после точки). 

7. Установить index = 0 (индекс для записи результирующей строки). 

8. Запустить цикл for для i от 0 до len-1 (перебор всех символов исходной строки): 

a. Если end == true И текущий символ не является пробелом и не является точкой (то есть найден первый символ первого слова предложения): 

i. Запустить вложенный цикл while, который пропускает все символы текущего слова (пока не встретится пробел, точка или конец строки), увеличивая i. 

ii. Установить end = false (первое слово текущего предложения пропущено). 

b. Если текущий индекс i всё ещё меньше len: 

i. Проверить, является ли текущий символ text[i] точкой. Если да, установить end = true (следующее слово после точки будет началом нового предложения). 

ii. Скопировать текущий символ text[i] в позицию text[index], затем увеличить index на 1. 

9. После завершения цикла установить символ конца строки text[index] = '\0'. 

10. Вывести обработанную строку text на экран. 

11. Конец программы.
